# 提示词进阶工艺（工程层）

> 何时读：多阶段/长镜头提示词打不准、画面漂移、多素材互相污染，或想系统提升提示词质量时。

## 一、三作用域法则（防漂移第一法则）

写提示词前，先按「管什么用」把事情分三层。**指令放错位置是漂移最常见的成因**——写在第一拍里的全局规则，到第四拍就失效了。

| 作用域 | 管什么 | 放什么 |
|---|---|---|
| **Global 全局** | 整条片子 | 片种、场景、风格、一句话前提、摄影总原则 |
| **Locks 锁定** | 任何不许漂的东西 | 身份、参考角色分工、音频来源、连续性、负向词 |
| **Time 时间** | 一拍/一个阶段 | 阶段事件与其末态 |

**末尾重述**：把最贵的两三条 Locks 在提示词末尾再写一次（模型对末尾内容更敏感）。这是位置约定，不是第四个作用域——内容仍属于 Locks。

## 二、末态法则（多事件提示词最高杠杆的一条）

凡是超过一个事件，就给每个阶段写**视觉上可见的末态**。它把「保持连贯」变成模型能瞄准、你能检查的东西。

- 弱：两人继续整理花束
- 强：末态——花艺师左手持花束；剪刀回到工作台右侧

末态必须可见。「她感到释然」不是末态；「肩膀松下来、皱眉消失」才是。每个阶段的提示词都以一句「末态：……」收尾。

## 三、时间粒度（先决定，再写拍点）

粒度是前置决定，写错了要整篇重写。

| 粒度 | 什么时候用 |
|---|---|
| 无时间戳，只写事件顺序 | 连续动作、情绪段落、单镜。加时间戳反而把镜头切碎 |
| **阶段 + 末态** | 大多数叙事内容（**默认**） |
| 秒级 | 仅当有外部硬约束：卡音乐、对口型、接缝交接、拍点必须落在固定秒 |

时间戳是时间预算分配，不是帧级剪辑点，动作可能略早或略晚于边界；别要求一秒里塞三个明显动作这种不可能密度。

**词锚定优先于秒锚定（改词与多语言迭代场景）**：需要反复改词、做多语言版本或多套文案的台词段落，把结构锚在「词」上而不是秒上——保持词序骨架（第几个位置放什么功能的话），只替换每个词位的内容，让时间轴按台词语速折算重新流动（镜头时长 ≥ 台词字数 ÷ 5，见 SKILL.md 黄金节奏）。手排的秒表在改词后必然整体失准；词锚定让节奏跟着新文本走，镜头顺序、字幕出现位、卡点关系不变。

## 四、多素材绑定（素材多≠画面好）

目标不是让每份素材都出现，而是**让模型为当前时刻选对素材**。素材更多但关系不更清楚，产出只会更差。

**一次一步：**

1. **逐主体绑定**：一个主体一行，写明这份素材控什么、不许从它拿什么。
   ```
   角色A 对应 @image1。只使用外形、发型和服装。
   场景A 参考 @image4。只使用空间布局与光照。不要用图中的人。
   ```
   绝不要写「@image1 到 @image4 分别定义四个角色」——没说是哪个对哪个，等于什么都没说。
2. **多视角要写输出数量**：几张图是同一物体的不同角度时，明说「三张图定义的是同一盏灯，全片只出现一盏灯」。不写数量，多视角素材是「物体被复制」最常见的成因。
3. **道具归属**：「样品箱 → @image5，只属于修复师」。这行最常被省略、又最需要——它防止道具中途换主人。
4. **按场景挑素材**：每个场景只点它要用的素材，加末态。
   ```
   场景1｜修复实验室内检查
   使用：修复师、样品箱、实验室、@video1 的开箱动作。
   事件：……  末态：……
   ```
   不做挑选，模型会试图在每个镜头里满足所有素材——这就是画面拥挤的实际成因。

**素材量参考**（稳定性区间，非能力上限）：

| 素材 | 稳定 | 可行但不稳 |
|---|---|---|
| 主体图里的不同主体 | 1–8 个 | 9–12 个 |
| 每主体参考片时长 | 5–10s | 更长 |

**视角与身份输入**：约五个主体内单/多视角均可，超过后优先单视角；需要多视角时一张视角一张图，拼图常被读成多个主体。**身份输入用「一张干净脸部特写 + 一张单独全身图」**，不要用正/侧/背拼成一图的三视图当身份输入（会被读成多个人；三视图另有专门用途，见 `face-workarounds.md`）。

**参考视频已定义运动时**：只写要继承哪些属性（如「参考 @video1 的运镜和动作节奏」），不要再把同一段运动用文字描述一遍——文字会和参考素材打架。粗白模是例外（它只提供运动和空间，主体/场景/风格仍需文字定义）。

## 五、复查顺序（验收时按此序）

身份 → Locks → 阶段末态 → 构图 → 运动 → 接缝 → 音频。

**停在第一个失败处**——身份错了，后面的检查都是白费。重生成时只重做失败的那一个镜头/片段。

## 六、模型实测档案（编写时点行为，会漂移）

**Seedance 2.0（实测）**：

| 项 | 行为 |
|---|---|
| 多镜头 | 能——一次生成可含带切点的有序段落 |
| 时序遵循 | 15s 的片子拍点整体晚约 2 秒；段落顺序稳 → **优先用分段（阶段+末态）**；必须秒级时把拍点写早 |
| 超载 | 15 秒装四个以上不同状态变化会**整段跳过**（丢的不是延迟）——约 4 个状态变化是上限，超过就缩短每段或拆请求 |
| 图 vs 文字 | **图赢**。参考图定义构图时，删掉文字里写的构图（它反正会输，只是噪音） |
| 长提示词 | 耐受性高（千字级不崩） |
| 已知失败 | 小字乱码（重要文字走后期）、枚举列表漏项、写明的运镜偶尔被跳过（把运镜写成该段主要意图） |

**Seedance 2.5（规格：CLI 实查 2026-10-10 已回填；行为：探测待跑）**：时长 4–30s（步进 1s）；素材 ≤30 图 / ≤10 视频 / ≤10 音频（总量 ≤50）；提示词上限 15000 字符；支持仅传音频；多视图主体参考自 2.5 起支持（拆单角度单图）；编辑 / 延长 / 白模参考等已确认——完整规格与积分见 `jimeng-seedance-2.5.md`。**行为仍需探测**：不要把 2.0 的经验直接套到 2.5 上；四个探测清单：①素材寻址（一次生成绑两份素材）②时序遵循（同一 spec 分段与秒级各跑一遍）③多余字幕与音乐（完全不写负向跑一次）④素材上限实际拐点。结果记回本文件并按**复测判定**格式回填（reproduced / degraded / failed + 样本数，见 `jimeng-seedance-2.5.md` 行为复测判定节），负面结果同样记。

⚠️ **别信参数表**：平台文档多次比实际更窄，直接提交你真正想要的值——被拒不创建任务、不花钱。

## 七、负向约束与词根（否定失效三改法）

**核心实测**：视频模型对否定词不敏感、对**词根**敏感——「不发光」里的「发光」、「没有笑」里的「笑」、「不要空镜」里的「空镜」，哪怕挂着「不 / 禁 / 无」，只要词根留在提示词里，就可能被当画面词渲染。否定式写法对**高关联概念**（光效 / 表情 / 开场构图这类与画面强绑定的词）基本失效；对**低关联瑕疵**（字幕 / 水印 / 变形）反而好用——两类分开对待。

**高关联概念三改法**（目标：被禁词根在提示词任何位置零出现）：

1. **换词**——改写正向描述，让词根不出现：
   - ❌「玉佩不发光、不透光」 → ✅「玉面呈青玉原色，哑光石质」
   - ❌「面无笑意」 → ✅「双唇抿紧、嘴角向下压、下颌绷紧」
2. **主体优先句式**——段首（锚定句）第一个分句就是画面主体（人名 / 身体局部 / 「画面主体：」），环境词开头会诱导模型给出空场景。
3. **触发器移除**——换掉诱发被禁效果的动作 / 构图：道具别靠近光源（「举到灯旁受光」必发光，「只佩戴 / 把玩」才安全）；别写会读成光源的光路描写（「映出火光」这类反射句，模型会把光源画到道具上）。

**栏目纪律**：提示词里的「禁止项 / 负面清单」栏只装**低关联**负面清单（画面变形 / 手部异常 / 服装突变 / 现代元素 / 字幕 / Logo / 水印；文字；音频）——正向执行指令**禁入**该栏（写进去既不当禁令也不当指令），高关联概念的否定式禁令**同样禁入**（等于废纸）。正向指令一律回到正常描写位（画面段 / 风格段 / 站位段）。

**适用边界**：词根渲染行为来自同业实测记录（manju-laoli-skill 项目拉片，单例性质）——写进项目实测档案时按 `continuity-log.md` 证据分级标注，别把单例当铁律。低关联瑕疵的否定式兜底不受本节影响：「no subtitles / 无水印」照写。

## 八、词句层：空词、运镜、步态与完成态

前七节讲工程层（结构、时间、素材、否定）。这一节讲句子本身，改一个词就能改变结果的部分。

### 8.1 空词表

写了不改变画面，只稀释有效信息。正向提示词里命中即删或改写：

cinematic、masterpiece、8K、4K、hyper-realistic、ultra-detailed、award-winning、stunning、epic、beautiful，以及中文的电影感、大片感、高级感、极致画质、超高清、壁纸级、震撼、完美无瑕、大师级。分辨率是平台参数，不是提示词。

`perfect anatomy` 这类「完美人体」也不要写进正向。写全身完整反而提醒模型构造整个人体，手部失败率上升。正确做法是收紧构图让手不出画，或把 extra fingers、fused fingers 放进负面词。

改写判据：没读过脚本的人能不能照着演出来。能演，模型就能拍；对方反问「怎么演」，说明还在写意图。

### 8.2 抽象词转写五步

1. 说出抽象词，例如「她犹豫」。
2. 问：一米外的摄影机，三秒内会录到什么。
3. 只挑一个会改变状态的部位，不要同时写脸、手、肩。
4. 给它动词、方向、幅度。
5. 删掉抽象词本身，不要留着「作为语境」。

| 低产写法 | 改成可拍摄行为 |
| --- | --- |
| 她犹豫 | 抬起的手停在离门五厘米处，两拍后放回身侧，没有碰到门 |
| 他很生气 | 下颌收紧，手在身侧握拳到指节发白，没有抬声音也没有动 |
| 走得很优雅 | 步幅稳定、速度均匀、转身时重心不晃、落步没有顿挫 |
| 很有气场 | 肩背打开，下巴平，目光越过镜头，步频比常人慢一档 |
| 电影感光线 | 单侧硬光从画面左侧打来，脸右侧落入阴影，背景压暗两档 |
| 高端面料 | 哑光真丝，斜光下可见细密织纹，褶皱边缘有柔和反光 |

动作词库按九类组织，每句只取一个主动作：移动与步态、手与臂、头与视线、躯干与体态、面部微动、物体交互、跌倒与撞击、呼吸、衣料与头发。环境动态每镜只选一个主元素。

### 8.3 运镜消歧

模型常把推镜和变焦混成同一次中心裁切。推镜是机位前进，近处物体比远处长得快，背景从画面边缘向外扩；变焦是焦距变化，画面里所有东西同比例放大，前后关系不变。

| 要的效果 | 写法 | 不要写 |
| --- | --- | --- |
| 机位向前 | 镜头向前推进，人物比背景长得快，焦距不变 | 推近 |
| 机位向后 | 镜头向后拉，画面边缘露出更多空间，焦距不变 | 拉远 |
| 焦距变化 | 机位不动，镜头变焦推近，人物与背景同比例放大 | 镜头向前 |
| 横向移动 | 镜头沿平行于背景的方向横移，近处物体移动更快 | 向左摇 |
| 原地转动 | 机位不动，镜头水平向左摇 | 向左移 |
| 垂直升降 | 机位垂直升高约一米，俯仰角不变 | 向上摇 |
| 环绕 | 镜头绕人物顺时针转约三十度，人物保持画面中心 | 转动镜头 |
| 固定 | 机位锁定在三脚架上，全程不动 | 不写机位 |

三条硬规则：一镜只写一个主运镜；「摇镜头」必须写横摇或纵摇；「长镜头」指长时镜头，不是长焦。

### 8.4 步态物理锁

走路是生成模型最容易出错的动作。模型画的是走路的样子，不跑步态约束，于是出现脚底打滑、双脚同时离地、同一只脚连迈两次、身体平移而腿不动。凡是人物行进的镜头，在第一次出现行进时加：

```
人物沿直线行进，脚跟先落地，前脚掌过渡到全脚掌，左右脚严格交替，始终有一只脚着地。
```

两人并排再加「肩并肩、同一纵深线、头部同高」，否则一个会走到前面，画面读成两段独立的行走。

### 8.5 完成态

动作在时长用完之前必须抵达一个可见状态。写法是「结束在什么状态，什么已经停止」：

- 行进镜：转身站稳后向远处迈出第一步，镜头末段减速停稳，结束时已走出画面中段。
- 单人展示：走位停在画面中心，重心落定，衣摆停止摆动，镜头停稳。
- 开场：镜头停在略高于平视的全景，灯光已亮定，画面静止一拍。

没有完成态，模型会把动作拖到最后一帧，或者动作做完后倒着播一遍。

### 8.6 三个高频故障

- **动作倒放**：短动作占不满时长，模型用倒放填满。对策是把两到三个同方向动作串起来占满全片，机位运动写明终点。
- **截断动作**：切点落在动作完成之前。对策是写完成态，并让它稳住再结束；需要快切时，下一镜从结果已经开始的状态起拍。
- **多运镜过载**：手持、升起、推进、移焦同时出现，画面读成抖动。对策是一镜一类；复合运镜写清阶段，例如前两秒低位推进，随后升高侧移，最后减速停稳。

### 8.7 身份块与运动块

固定角色跨镜出现时，把提示词拆成两块，不混写。身份块只写静态外观，运动块只写动作与机位。混写会让身份漂移。

```
身份块：与 @图1 为同一人，脸型、五官、发型、肤色、体型完全一致；一张图内多角度为同一个人、同一套服装。
运动块：站姿自然，重心落在双脚之间，双手垂在身侧，头部正对镜头；表情放松，不对镜笑。
```

### 8.8 五段式骨架（叙事线可选）

需要完整叙事时（多段一镜到底、绘画动画、新题材短片），按五段写，顺序固定：

1. 核心主题：三到六个标签，从画面类型到题材到美学，用竖线分隔。
2. 人物与基础设定：面部、服装、场景各一行，写材质与可复现细节。
3. 氛围与画质：光源、方向、色温、画幅、质感。
4. 运镜规则：一个主运镜、角度、镜尾落点。
5. 分镜时间轴：按秒或按段切片，每段写动作、镜头、必要的材质反馈。

只借结构，不借外部模板里的摄影机型号、胶片颗粒、低饱和调色。风格层按项目自己的光线口径写。

### 8.9 失败编码与机检

把被拒片段按症状编码，跨版本才能统计哪类失败最多。常用十二类：

| 编码 | 症状 | 首选对策 |
| --- | --- | --- |
| F01 | 换脸、双胞胎、服装中途变化 | 身份块写死，缩短时长，推近让人脸占更多像素 |
| F02 | 花型放大、颜色偏移、纹样变形 | 以基准图为唯一依据，避免微距特写花型 |
| F03 | 静帧感、只有镜头在动 | 补身体重心转移与衣料摆动两层运动 |
| F05 | 动作没做完、切点在半途 | 补完成态句，缩短时长或拆镜 |
| F06 | 动作倒放、来回踱步 | 同方向动作串接，机位写终点 |
| F07 | 脚底打滑、身体平移腿不动 | 补步态物理锁 |
| F09 | 说固定机位还在推、镜头自己晃 | 只留一个主运镜，补禁止项 |
| F10 | 多运镜混成抖动 | 一镜一类，复合运镜分阶段 |
| F11 | 相邻镜接不上、色调跳变 | 主体登记与色调句逐字复制，核对场景 state |
| F12 | 多出人物或物件 | 写清人数与职责，收紧构图 |
| F17 | 头脚被裁、景别失控 | 写终点景别与主体位置 |
| F19 | 手在动物件没变、道具消失 | 写材质反馈与遮挡关系，关键物件全程在画面内 |

成本从低到高：改一句提示词、改参数、原样重抽最多两次、重做参考图、拆镜或剪掉。同一镜同一设计三次失败，改设计不改措辞。
