# 画风与光影词典

> 何时读：定全剧画风、写场景光线、风格反复漂移、或要把「国风」「赛博」这类词翻译成可执行的画面描述时。

选画风的时间点是**开剧一次定、全剧贯通不改**（见 `asset-workflow.md` 锚点法与 `scene-plates.md` 场景板）。本文给的是「怎么把画风写成可复现的句子」，不是「哪个画风更火」。

## 一、画风必须写成三层，不能只写名字

只写「韩漫风」「国漫风」，模型按自己的理解选一种，同一项目跨镜就会在韩漫、日漫、3D 之间漂。画风词拆成三层，缺哪层都会漂：

| 层 | 写什么 | 例 |
|---|---|---|
| 线条 | 粗细、是否闭合、有无描边 | 线条细而均匀、外轮廓略粗于内线、无黑色描边 |
| 上色 | 平涂/厚涂、阴影边界软硬、高光形态 | 平涂为主，阴影边缘硬，高光为小块矩形而非渐变 |
| 色板 | 主色、辅助色、禁用色 | 主色墨黑与朱红，辅助色米白与青灰，不用荧光色 |

三层写全，画风才可复现；只写名字，换个人重出就变样。

## 二、主流画风的三层写法

| 画风 | 线条 | 上色 | 色板与质感 |
|---|---|---|---|
| 韩式漫剧 | 细而均匀，轮廓线略粗，人物边缘干净 | 平涂加柔和渐变，面部阴影集中在眼窝与下颌 | 高明度低饱和，肤色透亮，背景多用冷灰压住 |
| 日式动画 | 轮廓线闭合清晰，内线细，线条有轻重变化 | 赛璐璐平涂，阴影边界明确，边缘有一道亮边 | 高饱和但明度分层清楚，天空与逆光常带光晕 |
| 国风玄幻 | 线条飘逸、有顿挫，服饰褶皱线多 | 厚涂为主，水墨晕染与金箔质感并存 | 中国红、墨黑、鎏金、青蓝，整体压低明度求厚重 |
| 国风写实 | 线条弱化接近无描边，靠明暗塑形 | 厚涂加材质层，布料与金属分别处理 | 低饱和暖灰、黛青，光线偏柔和 |
| 现代写实 | 无描边，轮廓靠明暗对比 | 真实材质，皮肤有毛孔与微小瑕疵 | 自然色，白平衡偏中性，对比不过度 |
| 赛博朋克 | 锐利简洁，霓虹轮廓光明显 | 高对比硬光，光源色直接染在主体上 | 紫、蓝、粉、青，黑为底，湿地面强反射 |
| 暗黑悬疑 | 厚重，阴影面积大，线条粗 | 低明度，阴影中保留细节而非死黑 | 黑、深灰、暗红，冷白点光 |
| 治愈田园 | 柔和圆润，线条细且不强调 | 水彩质感，边缘轻微晕开 | 浅绿、米黄、天蓝，高明度低对比 |
| 蒸汽朋克 | 硬朗，机械结构线密 | 金属质感厚，铜锈与油污可见 | 棕褐、铜色、暗金，颗粒质感 |
| 美式卡通 | 粗黑描边，形状几何化 | 纯色平涂无渐变，阴影为整块 | 高饱和撞色，明度差异大 |

## 三、画风词的正确用法：翻译成可见特征

画风名是给协作者看的分类，给模型看的是特征。同一个词换成可执行描述：

| 空泛写法 | 改成可执行 |
| --- | --- |
| 韩漫风，精致 | 线条细而均匀、外轮廓略粗；面部平涂，眼窝与下颌各一块柔和阴影；肤色透亮高明度，背景压成冷灰 |
| 国风，唯美 | 线条飘逸带顿挫，衣褶线密集；厚涂，墨色晕染过渡，金饰有反光点；主色墨黑朱红，配青灰，明度压低 |
| 赛博朋克，未来感 | 霓虹色光源从画面外侧打在人物边缘形成轮廓光；黑底上紫蓝粉三色，湿地面强反射；高对比硬光，阴影中保留细节 |
| 治愈系，温馨 | 线条圆润不强调，水彩边缘轻微晕开；浅绿米黄为主，高明度低对比；光线为漫射，无硬阴影 |

**画风与质量词会互相稀释**：写实画风配「赛璐璐平涂」、动画画风配「超写实皮肤质感」，模型会在两种处理之间摇摆。质量词按画风二选一，见 `agent-prompt.md` 必加质量词条。

## 四、光影：光源必须先可解释

光线写不好，根因是没交代光源从哪来、多大、什么色。三个要素缺一，模型就自己编，编出来的光往往与场景物理不符（室内无窗却有夕阳斜射）。

| 要素 | 写什么 | 例 |
|---|---|---|
| 光源 | 是什么在发光 | 落地窗、台灯、路灯、霓虹招牌、烛火、月光 |
| 方向 | 从人物哪一侧来 | 从画面左侧来、从人物身后逆射、从正上方垂直向下 |
| 性质 | 软硬与色温 | 硬光边缘锐利、软光边缘晕开、偏暖、偏冷 |

三件套写完，才能叠情绪。常见组合：

| 情绪 | 光的写法 |
| --- | --- |
| 浪漫 | 光源在人物身后偏侧，人物轮廓有一道暖色亮边，正脸靠反光补亮，整体偏暖、阴影柔和 |
| 紧张 | 单一硬光源从一侧打来，脸的另一半落入深阴影，背景压暗，边缘锐利 |
| 神秘 | 只有轮廓光，正脸几乎无光，环境几乎全黑，仅保留轮廓与一处高光 |
| 压抑 | 光源来自正上方或极低处，人物眼窝落入阴影，色调偏冷，整体明度低 |
| 温馨 | 多个小面积暖光源（台灯、烛火、窗光），阴影柔和，明暗过渡平缓 |
| 梦幻 | 光源不明，画面整体发亮，边缘泛白，光晕扩散，对比度低 |

## 五、场景层面的风格统一

跨镜漂移多发生在场景而不是人物。控制手段是场景板里的固定句（见 `scene-plates.md`）：同一场景的所有镜头**逐字复制**锁定句，不改写、不简化。

场景统一四件事：

1. **风格词固定**：全片同一组画风三层描述，每个场景板里原样写一遍。
2. **光线基准固定**：同一场景的 state 决定光线，白天/夜晚/雨夜各自一套，跨 state 就是跨场景，要整批换图。
3. **锚点细节固定**：每个场景留两处唯一性视觉锚点（一块特定地砖、一盏特定吊灯），所有镜头里都在同一位置。
4. **禁用元素显式化**：古风场景不需要汽车霓虹、现代场景不该出现飞檐。这类写进负面清单是合法的——它们是低关联瑕疵词，不影响正向描述（见 `prompt-craft.md` 第七节「栏目纪律」）。

## 六、背景提示词的六段式

写场景图（不是分镜图）时的顺序，与 `agent-prompt.md` 场景九宫格模板配套：

1. 风格三层（线条/上色/色板）
2. 场景主体与空间规模（什么空间、多大、纵深如何）
3. 时间与天气（决定光线的物理来源）
4. 光源三件套（光源、方向、性质）
5. 细节元素（两处锚点 + 材质）
6. 构图与视角（机位高度、景别、画幅）

空场规则、文字政策、state 建模见 `scene-plates.md`，本文不重复。
