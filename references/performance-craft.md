# 表演层（Performance Craft）

> 用途：07 段的方法档。把「表演」从提示词里一句形容词，变成可写的具体行为。
> 定位：补 `facs-micro-expression.md`（微表情四区）与 `action-previs.md`（打戏动力链）之间的空白——它们管脸和打，这篇管**整段戏里的人在追求什么**。
> 核心公理：**表演是压力下的行为，不是情绪的展示。**

## 一、为什么需要这一段

AI 视频里最常见的表演败笔不是「表情不对」，是「人在等着说台词」：说到自己那句才有反应，说完就关掉。写提示词时如果只写「她愤怒地看着他」，模型只能画出一个愤怒的脸，画不出一个在争取什么的人。

这一段给的是**写提示词之前**的东西：这个人在这一场想要什么、被什么挡住、用了什么手段、什么时候换手段。

## 二、五支柱（每个角色每条戏都要过）

### 2.1 目标

角色在这一刻想从**某个具体的人**那里得到什么。

必须是**指向搭档的动词**：「逼他认罪」「求她再给一周」「说服他我不怕」。
不能是状态：「感到愤怒」「感到内疚」——状态演不出来。

判据：把目标念出来，能不能想象出一个人为此做什么动作？不能就是抽象了。

### 2.2 障碍与赌注

**障碍**：什么阻止他拿到目标。外部（对方想要相反的结果、有目击者、时间不够）或内部（自尊不允许他求人、他自己都不信）。

**赌注**：失败会怎样。答案必须让这个角色害怕。如果失败无所谓，这场戏没有张力。

### 2.3 策略

他此刻用的具体手段：施压、示弱、讨好、羞辱、恳求、威胁、拖延、转移话题。

**策略是动作动词，不是情绪词**。「冷酷」不是策略，「不看他眼睛地把杯子推回去」是。

活人会在策略失败后换策略；整场只用一种策略，演出来就是木头。

### 2.4 节奏点

节奏点 = 最小动作单元：这段时间里只要一样东西、只用一种方式。

**结束时点**：目标达成、策略失败、新信息出现、权力关系变化。

**每个节奏点变化必须在行为上看得见**：一个停顿、换姿势、语速变了、眼神移开。

判据：一场戏有 2-4 个节奏点变化。全程行为无变化 = 这场戏演出来会很平。

### 2.5 潜台词

他真正想要的和嘴上说的相反。潜台词不是演出来的，是**藏着失败时漏出来的**。

可写的标记：

- 用陈述句提问（「你昨晚很忙。」）
- 重复同一个问题（因为不信答案）
- 生硬地换话题
- 在不合时宜的时刻开玩笑（防御脆弱）
- 回答太短（「行。」「当然。」= 关上门）

## 三、倾听与反应（质量的终极判据）

表演的生命在台词之间，不在台词里。写提示词时要写出来的可见标记：

1. **反应在对方说完之前开始**。听到半句就抓住重点，脸已经开始答。等对方说完再「启动」反应，是死板。
2. **思考先于说话**。回答难题前有一个小停顿——明显在决定说什么。匀速即时回答 = 背台词。
3. **评估的瞬间**。听到重要的事需要时间消化。特写镜头最值钱的就是这个瞬间：一张脸、眼神失焦、世界转了半圈。
4. **被对方的情绪带动**。被吼时要么回吼，要么刻意压低声音——但必须有回应，不能各演各的。

## 四、身体（写进提示词的物理层）

### 4.1 生理状态先于心理

| 参数 | 高 / 低 | 写进提示词的样子 |
|---|---|---|
| 重心 | 高=自信/攻击，低=疲惫/屈服 | 「下巴微抬，肩胛骨向后收」vs「肩膀垮着，头低半寸」 |
| 节奏 | 快=神经质/亢奋，慢=掌控/威胁 | 「手指连敲三下」vs「慢慢地放下杯子，停顿两秒」 |
| 开放度 | 开=坦诚，闭=防御 | 「双手摊在桌上」vs「双臂交叉，身体侧过去十五度」 |
| 呼吸 | 急=恐慌，缓=控制 | 「呼吸短，锁骨起伏明显」vs「胸口几乎不动」 |

**呼吸是状态最诚实的指示器**。刚跑完步的人不可能用平稳的声音说话——写提示词时这条比任何形容词都管用。

### 4.2 手头动作与打断

角色几乎总在**做别的什么事**：在擦杯子、数钱、修车、切菜——然后在这之上说话。手上有活，表演才有生活感。

**中断动作法则**：最重的强调是他**停下手里的事**。他一直在削苹果，说到某句突然停——这句话就成了大事件。写提示词时把「停止」当作标点来用。

### 4.3 距离（关系的可视化）

| 距离 | 含义 |
|---|---|
| < 0.5 米 | 亲密或暴力；不请自入即攻击 |
| 0.5-1.2 米 | 信任 |
| 1.2-3.5 米 | 公事、警惕 |
| > 3.5 米 | 疏离、等级 |

**距离的改变 = 节奏点改变**。谁靠近、谁打破距离、谁僵在原地不动，这些比台词说了什么更能说明关系。

### 4.4 地位

地位在行为里，不在身份里。

- 高地位：头不动、动作慢、凝视久、答话前有停顿、占据空间、动别人的东西。
- 低地位：瞎忙、频繁摸自己（摸脸、摸头发）、话碎、用笑填空白、用眼神征求许可。

**最有张力的结构是地位被打破**：老板有一秒钟露出恐惧；下属突然不笑了。

## 五、主档案（跨集一致性的载体）

每个反复出现的角色写一份主档案，**300-500 字，一段流畅中文**，全部可观察。之前写一次，之后每集只做「场景改编」，不改主档案。

### 5.1 模板

```
角色表演：【姓名】。【年龄、体型、体格、姿态——身体作为过往经历的档案】。
【一个从句概括心理引擎，解释这个体格的来由】。
声音特征：【音高或音色、口音、语速与表达方式、情绪下如何变调】。
关键的生理习惯与下意识小动作：【标志性小动作 + 触发条件；压力下的小动作 + 触发条件；
掩饰行为——做什么来隐藏真实感受；面具般的表情，以及面具破裂的确切条件】。
步态风格：【作为角色特征的步态，命名它，再拆重心、节奏、落脚点】。
然而，当【情绪触发点】时，【姿态、步态与脸如何变化】。
【唯一的软肋：唯一能让这张脸真正柔和下来的人或物】。
```

### 5.2 七条写法

1. **只写可观察的**。不写「他很紧张」，写「下唇抖、重重咽了一下、用嘴吸气再急促呼出」。
2. **每个小动作带触发器**。不写「他掰指关节」，写「他在日常闲聊里掰指关节，用来伪装自信」。格式：`[动作] + [时机或原因]`。
3. **给步态命名**再拆解。名字是记忆锚，拆解给出重心、步幅、躯干与头的状态。
4. **必写面具破裂的瞬间**。每份档案至少一个「然而，当 XX 时……」。一个同时在演两层真实的角色，才是人而不是木偶。
5. **软肋只能有一个**。一个人、一只动物、一件物。两个就稀释了。
6. **不写服装**。服装属于资产与分镜层，表演档案要能跨换装成立。
7. **不写摄影机、不写色彩**。表演只管动作、脸、声音。

### 5.3 眼神细节（必写项）

死鱼眼是 AI 生成表演最常见的问题。每个角色都要写：

- **视线追踪**：聚焦在他关心的人或物上，目光会因思考而漂移、快速扫过、落回来；不锁定在一个点。
- **眨眼质感**：压力下急促眨眼；掌控时缓慢开合；emotional 抽离时眨眼后失焦。
- **眼神光**：眼睛看起来湿润、有光、活着。
- **有控制的静止**：近乎不眨眼的平静，是刻意决定，不是卡帧；视线仍要有意图地缓慢移动。
- **眼睛先于头**：眼睛比头早一点到达目标。台词之前，想法已经在眼里。

## 六、场景改编（主档案怎么用到具体镜头）

主档案说的是「他是谁」，每一场要改写成「他此刻是什么状态」。

1. **只写在场角色**。不在画面里的人物不写段落。
2. **保持不动的内核**：身份、声音、标志动作、眼神细节、情感主线，每场一致。
3. **为当前场景重新表达**：选、强调、改、放弃某些行为，适配坐/站/跑/躲的体态与节奏点。
4. **转化而非删除**：这个场景里做不出的动作要转化——习惯踱步的人现在瘫在沙发上，就保持同一个神经质引擎，转移到身体微晃、手腕抽动、撕纸。
5. **一段流畅中文**，不用项目符号，不用标题。
6. **以参考标签开头**（若工作流用 @ 资产），让模型把表演绑到对的人。

### 声音（锁定的，不改）

表演按场改写；**声音是锁死的**。每个角色一条独立声音提示，有台词时一字不差地贴进提示词的音频字段，不按场景改。角色出场但没说话，就省略。

```
「【年龄】岁，【出身或口音】。【音色与音区】；【语速与说话方式】；
【情绪特征，以及压力下如何转变】。」
```

## 七、呈现状态而非过渡

视频模型在「过渡」上容易翻车，在「状态」上表现好。

- 好：「出拳瞬间，手臂伸展」
- 差：「把手伸进包里，掏出东西，准备挥拳」

按节奏点把状态串起来，而不是叙述连续过程。

## 八、群像

- **反应像波浪传递，不同步**：一个人先懂笑话，第二个慢半拍，第三个没懂。所有人同时同幅度反应很假。
- **反应比动作本身更值钱**：事件发生后最值钱的画面是看到它的人的脸。
- **面对威胁时的冻结**：群像平时有微小动作（换重心、手势、倾斜），威胁出现那一刻全部停止。从喧闹到静止的对比是最好的标点。
- **移动必须有动机**：走向某物或远离某物。有效的移动事件：逼近（升级）、转身（回避或藏表情）、别人坐着时站起来（夺主导）、冲突中途坐下（反常压制）、在门口停住（门槛=决定点）。
- **强者安静不动，弱者烦躁大喊**。危险感不靠危险的人演，靠周围人的紧张。
- **退化会累积**：角色被磨平的过程要在身体上逐场累积，不能在场景之间重置。

## 九、十五种败笔与修法

| # | 症状 | 在提示词里怎么修 |
|---|---|---|
| 1 | 脸在描绘情绪（挑眉、做鬼脸） | 删掉表情指令，改为写目标 + 给手一个任务 |
| 2 | 从第一秒就演出结局 | 只写角色此刻知道的信息 |
| 3 | 等台词时才反应 | 把反应写在对方说话的中间 |
| 4 | 整场一种策略 | 标出 2-4 个节奏点，每点换一个动作动词 |
| 5 | 手势图解台词（说「大」就张手） | 手势先于想法，或与台词相反，或干脆没有 |
| 6 | 无铺垫的哭或怒 | 写阶梯：克制 → 爆发；情绪必须有触发事件 |
| 7 | 体格与经历不符（恶棍有舞者体态） | 写身体档案：重心、节奏、磨损 |
| 8 | 底层人物说书面语 | 台词里加打断、吞音、重复 |
| 9 | 施暴前有「凶狠」停顿、缓慢转头 | 威胁是日常的，没有前摇 |
| 10 | 群像同时同幅反应 | 波浪式错开，改强度 |
| 11 | 死寂的停顿（什么都没发生） | 用评估瞬间或手头动作填，或删掉 |
| 12 | 重大事件后瞬间恢复 | 状态有惯性，余波带入下一拍 |
| 13 | 表演在向观众眨眼（喜剧尤其） | 让角色完全相信情境 |
| 14 | 特写里脸部肌肉过度活跃 | 景别越紧动作越少，只留眼睛和思考 |
| 15 | 死鱼眼 | 见 5.3，眼神细节不是可选项 |

## 十、自检（写完表演段落逐条过）

- [ ] 每个角色的目标是指向搭档的动词
- [ ] 障碍与赌注存在，失败的代价是真的
- [ ] 有 2-4 个节奏点变化，每个变化在行为上可见
- [ ] 反应在对方台词结束前开始，含评估瞬间
- [ ] 每个角色有手头动作，至少用了一次「打断动作」作为标点
- [ ] 距离有变化且变动有动机；地位体现在身体上
- [ ] 每个小动作有触发器；面具写了破裂条件
- [ ] 眼神细节明确写了：视线微动、眨眼质感、眼神光
- [ ] 有台词的角色贴了声音提示；没台词的省略了
- [ ] 呈现状态而非过渡
- [ ] 表演段落里没有服装、摄影机、色彩
- [ ] 群像反应错开
- [ ] 评分自测：这段描述能到 4 分吗

## 十一、五分制自评

| 分 | 是什么样 |
|---|---|
| 0 | 有文字，无行为 |
| 1 | 朗诵者：声情并茂的台词，身体图解意思 |
| 2 | 勤勉者：能猜出目标，但只有一种策略，反应滞后，停顿空洞 |
| 3 | 熟练工：有目标与节奏点，能听搭档，动作合理；缺潜台词与状态惯性 |
| 4 | 活人：行为连续，策略有反差，潜台词与台词背离，身体体现地位，反应先于台词，有一个出人意料但真实的选择 |
| 5 | 磁场：在 4 分之上有悖论——既好笑又可怕，既残忍又迷人，一边撒谎一边让人感动 |

**特写镜头要 4 分以上**；自测 2 分以下的段落必须重写才能发。
