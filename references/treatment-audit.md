# 分场审计与剧本融合（Treatment Audit & Script Fusion）

> 用途：04 段（分场大纲）与 05 段（剧本融合）的方法与门禁。
> 04 段的产出不是「写完就算」，要过逐场四问；05 段不是「重写一遍」，是把上游资产融合成可排产的剧本。

## 一、04 段：分场大纲

### 1.1 先确认场景总数（防暴走机制）

AI 最容易在分场阶段暴走：时长 10 分钟却写 50 场，或者 3 场就想讲完一个完整故事。所以**先算再写**。

按目标时长估算场景数：

| 目标时长 | 场景数量级 | 说明 |
|---|---|---|
| 60-180 秒（单集短剧/短视频） | 3-8 场 | 单场 15-40 秒 |
| 3-5 分钟 | 8-15 场 | |
| 20-40 分钟（长片单集） | 25-45 场 | 平均每场 45-60 秒 |

**流程**：先报「按 XX 分钟，我建议拆 XX 场，您看合适吗，或者直接告诉我您要多少场」→ 等用户确认 → 才写。

不确认就写，后面剧本段的篇幅会全部错位。

### 1.2 场次行格式

每场一行，字段固定：

```
场次 | 内外景·地点·日夜 | 一句话事件 | 押上的价值：开 → 结 | 结构位置
```

例：

```
场3 | 内景·茶棚·日 | 阿青擦杯子，老周带人进门要债 | 安全 → 威胁 | 第一幕·诱发事件
```

**「押上的价值：开 → 结」这一列是核心**。价值不转折的场，要么合并要么删。

### 1.3 逐场四问（写完必须逐场过）

1. **因果**：这一场发生，是不是因为上一场发生了某事？能用「因为……所以……」串起来吗？
2. **价值**：这一场的价值从什么变成什么？开与结是否不同？
3. **主旨**：这一场是否服务于主控思想？删掉它主题是否受损？
4. **必要性**：删掉这一场，故事是否立刻变差？如果只是「少了点气氛」，删。

**四问有一问答「否」，这一场必须重写或删除。**

### 1.4 六个审计标签

发现问题时用标签标出来，标完再改，不要边写边改。

| 标签 | 含义 | 修法 |
|---|---|---|
| `[因果]` | 这一场不是从上一场自然长出来的 | 补过渡场或改上一场的收尾 |
| `[价值]` | 没有价值运动（开与结相同） | 给主角一个具体的得失 |
| `[圣经]` | 与角色设定或世界观冲突 | 回 02 或 03 改设定，不在这里圆场 |
| `[节奏]` | 对该场功能来说太快或太慢 | 拆场或合并 |
| `[信息倾倒]` | 靠对白集中交代背景 | 改成行动展示（见 worldbuilding-rules 第四节） |
| `[重复]` | 重复了之前已经发生过的内容 | 删或合并 |

### 1.5 C 路径（爆款短剧）的节拍骨架

单集必须走完这个弧：

| 节拍 | 要求 |
|---|---|
| 黄金前 3 秒钩子 | 极度羞辱或致命危机的动作开场，不写对白 |
| 复合底牌激活 | 强制外化角色设定里的「隐藏底牌气场变化」与视觉异象 |
| 预期落空与绝地反扑 | 反派极限施压 → 主角瞬间反制；必须出现设定里的「逆鳞触发」或标志性微表情 |
| 极致爽感高潮 | 视觉张力拉满；周围人的反应要有层次（瘫软 / 震惊 / 后退，不同步） |
| 致命悬念钩子 | 反杀刚结束未等喘息，立刻切入下一层更大的危机 |

### 1.6 A/B 路径的节拍骨架

- **A 长片**：第一幕建置（含诱发事件）→ 第二幕对抗（冲突逐场升级，中点是重大胜利或失败的假象）→ 第三幕解决（危机抉择 → 高潮 → 结局）。每场都要比上一场更难。
- **B 艺术短片**：意图奠基 → 母题浮现与习惯手势外化 → 隐喻交织 → 意图沉淀或决堤 → 余音留白。没有传统动作高潮，用物理动作展现心理崩塌。

## 二、05 段：剧本融合

### 2.1 这一段到底做什么

不是重写故事，是**把四份上游资产融合成可排产的剧本**：

- 概念稿的人物与主控思想
- 角色圣经的声音与行为特征
- 世界观规则与知识层级
- 分场大纲的事件

**最高原则**：绝不篡改上游设定的底层参数；绝不给大纲注水加戏。

### 2.2 三步交互

**第一步：资产扫描单（等确认）**

读完四份资料后，回一份扫描单：

```
已扫描：
1. 故事纲要：核心冲突是 —— [一句话]
2. 人物圣经：已锁定角色 —— [姓名 + 核心需求]
3. 世界观：已提取规则 —— [规则 / 或「按现实法则处理」]
4. 分场大纲：共 [X] 场戏

体量检测：这 [X] 场是全部，还是长篇的第一批？
```

**为什么要问体量**：10 场可能是完整的 3 分钟短剧，也可能是 40 分钟长片的开头。判错会导致台词密度与节奏全部错位。

**第二步：密度分流（等确认）**

```
是否需要扩写台词？
【N】不扩写：只做融合与排版，保留大纲原台词，绝不加戏
【Y】需要扩写：请再说两件 —— 对标风格，以及台词密度（简要精炼 / 高密度交锋）
```

**第三步：矛盾拦截**

如果场次数与项目类型不匹配（例如 8 场却选了院线长片），先停下问清：是只要长片的台词质感，还是这只是第一批次？

### 2.3 融合的三条硬规则

1. **情节动作融合（防注水）**：严格执行分场大纲的事件。大纲没有的情节，哪怕一行，也不许自己加出来拖时长。
2. **世界观深度渲染（不改规则）**：动作描写里体现世界观的物理代价与信息差。
3. **台词与声音融合**：按角色圣经的口癖、防御姿态写台词；密度按用户选的档执行。

**密度两档的具体差别**：

| 档 | 做法 |
|---|---|
| 简要精炼 | 能用动作、眼神、停顿表达的一律不开口；台词极简 |
| 高密度交锋 | 连珠炮式密集对话，句句反击，信息量大 |

### 2.4 输出格式

```
[场号]. [内景/外景]. [具体地点] - [时间]

[客观视听动作描述。初次登场加粗：**姓名（年龄）**]

角色名字
（微表情/动作提示，仅必要时加）
「对白内容。」
```

### 2.5 机检

`python scripts/check_script.py <剧本.md>` 查九项：

| 项 | 查什么 | 级别 |
|---|---|---|
| S1 | 可解析（UTF-8/GBK 自动识别） | 错误 |
| S2 | 集号与目录一致 | 错误 |
| S3 | 模板占位残留（TODO/XXX/占位/待填） | 错误 |
| S4 | @引用名清单 | 提示 |
| S5/S6 | 钩子与收尾是否敷衍 | 警告 |
| S7 | 场次编号连续 | 警告 |
| S8 | 台词时长预算（4.3 字/秒折算） | 警告 |
| S9 | 空场 | 警告 |

**机检不判内容好坏**——它只查结构。内容质量走 `references/review-rubric.md` 的人工项。

## 三、两段的接缝

04 交出分场大纲后，05 段开工前必须做一件事：**把分场里的每一场，对照角色圣经检查这个角色是否在场且行为符合设定**。发现不符，回 04 改分场，不要在 05 里改人物——那会让 02 的设定失效。

同样，05 写完发现某场台词装不下（S8 超预算），回 04 拆场或精简事件，不要在 05 里硬压台词——压出来的台词没有呼吸空间。

## 四、纪律

1. **不确认场数不动笔**。
2. **不篡改上游**：发现上游有问题，回上游改，记录到修订日志。
3. **不注水**：大纲没有的戏不加。
4. **机检不过不交**：`check_script.py` 有错误级命中即返工。
5. **只声称读过实际读到的部分**：长剧本分批读时记录实际已读范围，未读标「待补」。
