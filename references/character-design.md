# 角色设定卡与逐镜一致性审查

> 何时读：新项目要立角色、角色跨集越做越不像、或要排查「同一个角色在不同镜头里为什么不是一个人」时。

`asset-workflow.md` 讲锚点法与 ref 红线（怎么出图），本文讲**出图之前要定什么、出图之后怎么查**。两者是同一件事的前后两段。

## 一、设定卡为什么必须结构化

「25 岁女性，长发，冷静」这种描述，三次生成能出三个不同的人。不是模型不行，是这条描述里的可变量太多：长发多长、什么发色、什么脸型、冷静是表情还是气质。

结构化设定卡的作用是把**可变项逐个锁死**，让每一条都成为可复现的约束。判定标准：把设定卡交给一个没看过剧本的人，他照着描述画出来，应该是同一个人。

## 二、设定卡七段（短剧版，比影视通用模板精简）

### 1. 基础档案

| 字段 | 要求 |
|---|---|
| 角色名 | 与 `素材/` 下文件名一致，@引用名逐字相同 |
| 年龄 | 写数字，不写「青年」「中年」 |
| 身份职业 | 一句话，决定服装与场景 |
| 角色定位 | 主角 / 对手 / 助力 / 功能性配角 |
| 性格三个词 | 只写三个，多了等于没写 |

### 2. 外貌（可直接出图）

| 部位 | 要写到什么程度 |
|---|---|
| 脸型 | 具体类型 + 一处辨识特征（下巴微尖 / 颧骨略高） |
| 眉 | 形状 + 粗细 + 走向 |
| 眼 | 眼型 + 瞳色 + 眼距或眼角特征 |
| 鼻 | 鼻梁高度 + 鼻头形状 |
| 唇 | 厚薄 + 唇形 + 自然唇色 |
| 皮肤 | 肤色 + 质感（透亮 / 有细微瑕疵 / 偏哑光） |
| 发型 | 长度 + 造型 + 发色 + 刘海 |
| 体型 | 身高 + 体型 + 一处体态特征（肩线 / 颈长 / 腰线位置） |

### 3. 标志性元素（至少三个）

这是跨镜识别的锚点，比五官更容易被模型稳定复现。分三类，各取其一最好：

- 固定配饰：某只耳朵的一枚耳钉、左手腕的表、颈后一颗痣
- 固定服装元素：领口的某种扣型、袖口的缝线、腰间的挂件
- 固定动作习惯：紧张时摸耳钉、思考时咬下唇、生气时抱臂

配饰与服装元素进提示词；动作习惯进表演设计。**痣、疤、纹身这类位置型特征必须写明左右与大致方位**，否则模型会左右颠倒。

### 4. 服装系统（三套起）

每套写清六项：上装、下装、外搭、鞋、配饰、适用场景。

三套的划分不是审美考虑，是**剧情节点考虑**：日常装（多数镜头）、正式装（关键场面）、特殊装（转折或战斗）。同一套在跨集复用时不改细节，改一处就要整批换图。

### 5. 语言风格

| 场合 | 写什么 |
|---|---|
| 日常 | 句式长短、用词层级、口头习惯 |
| 生气 | 变调方式（语速加快 / 变慢压低 / 沉默） |
| 悲伤 | 是否掩饰、是否直接表达 |
| 三句示例 | 同一角色的三句台词，供配音与台词改写对照 |

语言风格落到 `audio-voice.md` 的音色表与 `scripts/tts_voice.py` 的 style 标注。

### 6. 关系网络

不用画图，三行足够：与主角的关系、与对手的关系、隐藏关系（第几集揭露）。隐藏关系影响表演设计——提前知情与不知情的角色，在同一场戏里的反应时差不同（见 `agent-prompt.md` 多人场景预排「视线与反应」）。

### 7. 出场状态弧

按故事阶段写三档：初期（什么状态）、中期（转折后）、后期（结局前）。同一角色跨阶段的外形可能只差一处（发型变了、换了配饰），但表演基调会变——这是导演侧的依据，不是出图依据。

## 三、跨镜一致性五维审查

素材出完之后，逐镜验收按五个维度查。**停在第一个不合格处**，因为脸不对时查服装是白费。

| 维度 | 查什么 | 不合格的表现 |
|---|---|---|
| 面部 | 五官相对位置、痣疤等标记、眼神方向 | 脸型变了、眼距变了、痣换了边 |
| 发型 | 长度、分缝、纹理、发色 | 刘海形状变了、发色偏冷或偏暖 |
| 服饰 | 款式、颜色、配饰位置、褶皱走向 | 领口变了、配饰换了手、腰线高低变了 |
| 体型 | 比例、身高差、肩宽、腰线 | 与同框角色身高关系变了 |
| 画风 | 线条粗细、上色方式、阴影处理 | 某一镜变成另一种画风（最常见于跨场景） |

画风那一维最容易漏查，因为单看一镜没错，放在一起才跳。抽查方法：取三镜首帧并排看，比对线条粗细与阴影硬软。

## 四、三类高频漂移的成因与对策

| 症状 | 常见成因 | 对策 |
|---|---|---|
| 换脸 | 镜头提示词里重描了外貌（ref 被文字覆盖） | 删掉镜头提示词里的外貌描述，只留动作/景别/运镜（见 `asset-workflow.md` 第四节） |
| 服装中途变化 | 同一角色用了两套服装素材，或服装描述在不同镜里不一致 | 场景板式锁定：服装句逐字复制，不做同义改写 |
| 同框角色混淆 | 同镜 ref 数量超红线（3 个以上保真率骤降） | 1 主 ref + 其余文字或剪影，需要保真的角色单独给镜头（见 `asset-workflow.md` 第三节） |

另有一类不是漂移而是设计问题：角色在跨集时**造型本来就该变**（换了生活阶段）。这种要按新造型补一套素材，不是修旧图。

## 五、复用的边界

设定卡本身可跨项目复用（同一画风的现代都市剧，主角卡改几处就能用）。但**素材图不能跨项目复用**——同一张脸出现在两部剧里，观众会认成同一角色。跨项目复用只到「设定卡结构 + 画风三层描述」为止。
