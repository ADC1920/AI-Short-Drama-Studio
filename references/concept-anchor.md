## 一、这一段的唯一产出

`01_story/synopsis.md`，顶部标注「待人工确认」与版本号。

**不做**：角色圣经、世界观、分场、剧本、图像提示词、表演稿、视频提示词。这些是后续段的事，写进概念稿就是越界。

## 二、路径判定（先问，不猜）

不同项目定位要的结构不同，混用会让后续全部错位。开工前确认一次：

```
请问项目定位是哪一类？
【A】院线长片 / 经典剧集 —— 三幕式结构
【B】艺术短片 / 电影节向 —— 三层结构法
【C】流媒体 / 爆款短剧 —— 强爽感引擎
【D】自定义 —— 在 A/B/C 之上加个人设定
```

判据：**目标时长与投放场景**。60-180 秒竖屏单条 → C；多集竖屏短剧 → C；20-40 分钟单集 → A 或 B；艺术节投递 → B。

本项目的主力形态是短剧与短视频，所以 **C 路径是默认**；A 与 B 保留给长片与艺术片项目。

**路径不同不得串味**：C 路径的爆款引擎设定写进 B 路径的艺术片，会同时破坏两者。

## 三、路径 C：流媒体 / 爆款（默认）

短剧这一行的观众耐心以秒计，概念稿必须能回答「前 3 秒看什么、第 15 秒危机是什么、最后留什么钩子」。

### 3.1 复合引擎设定

- **绝境底色**：开篇最惨烈的遗憾或极度屈辱的处境。要具体到可拍摄（「被当众撕毁婚书」而非「过得很惨」）。
- **破局底牌**：主角手里的异于常人之处——系统、血脉、重生记忆、隐藏身份、专业技能。写清**能力边界与代价**，无代价的金手指没有戏剧张力。
- **融合逻辑**：多种元素如何自洽。例：「重生后系统才激活」比「重生 + 系统」各自独立更有说服力。

### 3.2 核心反转链（三层）

| 层 | 功能 | 判据 |
|---|---|---|
| 第一层 | 憋屈与危机 | 陷入看似无法翻盘的死局，观众要替主角憋屈 |
| 第二层 | 掀底牌 | 底牌在绝境中爆发，且爆发有代价或限制 |
| 第三层 | 极致打脸 | 降维打击，全场反应要有层次（不是所有人同时震惊） |

### 3.3 极速节点排布

`前 3 秒强视觉钩子 → 15 秒内诱发致命危机 → 极速动作高潮 → 结尾留强悬念`

这是单集的骨架。多集短剧里每集都要有这个完整弧，不是全剧只有一个。

### 3.4 人物基石

- **逆袭主体**：名字 / 表层身份 / 隐藏底牌
- **施压主体**：核心反派名字 / 势力 / 他掌握什么主角没有的东西

写这两项就够，完整三维人物表留到 02 段。

## 四、路径 A：长片 / 经典（三幕）

### 4.1 一句话故事（logline）

`【类型】的【主角】在【背景设定】中，遭遇了【核心冲突】，必须采取【关键行动】，而代价是【X】。`

判据：陌生人听一遍能复述，且能听出「代价」是什么。听不出代价就是没写清冲突。

### 4.2 主控思想

`当主角做了【Y】，因为【Z】，生活变成了【X】。`

这是价值判断句，不是情节摘要。「爱能战胜一切」不是主控思想，「当人用谎言保护所爱，因为谎言需要更多谎言支撑，最终失去所爱」才是。

### 4.3 其余要素

- 题材与基调（含 3-5 部参考影片）
- 目标时长与项目类型
- 主角：致命缺陷 / 渴望（外在）/ 需求（内在）/ 弧光（从 X 状态到 Y 状态）
- 反派：动机 / 他有什么主角没有的 / 与主角的镜像关系
- 诱发事件（前 1/4 处打破平衡的事件）
- 危机抉择（两种互不相容的价值之间选一个）
- 高潮（回应抉择的具体行动，全片最具动作性的点）
- 结局（1-2 句，新世界坐标）
- 主题与副主题 + 差异化
- 伏笔物件：第一幕埋、第三幕开，逐项写明埋在哪、开在哪

## 五、路径 B：艺术短片（三层结构法）

外部冲突弱化，状态与隐喻优先。

### 5.1 第一层：故事（表层叙事）

主角在特定物理空间中处于什么状态、遭遇了什么客观事件。判据：能用 3 句话说完，且都是可拍摄的事实。

### 5.2 第二层：隐喻

提取一个贯穿全片的物理物件或自然现象，隐喻主角的内心困境或社会处境。判据：这个物件必须**在画面里出现**，不能只是概念。

### 5.3 第三层：意图

| 维 | 项 | 写什么 |
|---|---|---|
| 创作初衷 | 审美 | 视听基调与美学追求 |
| | 语境 | 时代背景或边缘语境 |
| 意识形态 | 观念 | 要探讨的哲学或社会议题 |
| | 立场 | 批判 / 同情 / 凝视 |
| 风格 | 习惯手势 | 角色折射心理状态的标志性无意识动作 |
| | 母题 | 反复出现的视觉或主题元素 |

### 5.4 人物基石

主角 + 镜像人物或失语对象。弱化世俗敌友，只留折射内心的关系。

## 六、路径 D：自定义

在 A/B/C 任一套骨架之上，按用户给出的具体设定扩展。**先问清基础框架是哪一个**，再叠加自定义项；不问清就自创，等于把用户的想法替换成自己的。

## 七、写完自检

- [ ] 一句话故事能向陌生人说清，且带得出代价或钩子
- [ ] 路径选了哪一个、为什么选它，写在同一份稿里
- [ ] 主控思想（A/B 路径）或底牌与代价（C 路径）明确
- [ ] 没有任何后续段的产物（角色表、分场、台词、提示词）
- [ ] 顶部标「待人工确认」，未自己宣布通过

**不通过的样子**：概念稿里已经出现完整的第 1 场对白；或者写了「主角很惨」但没有一个可拍摄的画面；或者 C 路径的金手指没有代价，第三层打脸只靠「全场震惊」四个字。

## 八、与相邻段的边界

| 段 | 概念稿该给的 | 不该给的 |
|---|---|---|
| 02 角色 | 主角与反派的核心弱点与底牌方向 | 完整三维人物表、台词示例 |
| 04 分场 | 单集骨架（C 路径的极速节点排布） | 逐场大纲、场景编号 |
| 05 剧本 | 主控思想与危机抉择 | 任何对白 |
