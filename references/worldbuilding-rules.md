# 世界观规则（Worldbuilding Rules）

> 用途：03 段的模板与判定。这是可选段——现实题材可整段跳过，复杂规则题材（系统流、修仙、科幻、无限流、怪谈）必做。
> 为什么必须有硬规则：没有限制的设定就是万能解释器，所有冲突都能用它化解，戏就没了。

## 一、这一段解决什么

短剧里的「系统」「血脉」「异能」如果不定规则，会出现三个典型崩塌：

1. **无限变强**：下一集主角更强，观众失去期待。
2. **临时开挂**：写到需要就加一个新能力，前面没有铺垫。
3. **解释靠台词**：角色张口就说「你知道我们这世界的规矩是……」。

本段的目标就是把规则写死，让后续分场与剧本只能遵守、不能改。

## 二、规则四问

写完世界观必须能回答这四问，答不上就是没写完。

| 问 | 要求 | 不通过的样子 |
|---|---|---|
| 这个系统**能**做什么 | 能力清单，逐项可验证 | 写「无所不能」 |
| 这个系统**不能**做什么 | 硬限制，且限制会真正卡住主角 | 限制只是装饰，剧情从没被它拦住 |
| 使用的**代价**是什么 | 每次动用都要付，代价要能累积 | 代价只在设定里提一次，后面忘了 |
| **谁**能用谁不能用 | 能力分布决定权力结构 | 所有人都能用，等于没有门槛 |

**判据**：把「不能做」那几条拿掉，故事是否立刻变得没劲？如果没劲没了，说明限制是有效的。

## 三、模板

### 3.1 世界规则

**与我们的世界不同的地方**

- （逐条写，每条都要能在画面里看见或影响人物选择）

**与我们的世界相同的地方**

- （重力、生物、货币、国家、时间流逝——写清哪些没变，防止越写越飘）

**技术与超自然水平**

- 一句话定位：这是前工业、现代、近未来、还是完全架空的体系？

### 3.2 系统（如果有）

**系统能做到的**

- （清单，每项带一个典型使用场景）

**系统做不到的**

- （硬限制，逐项；这是全篇最重要的部分）

**使用代价**

- （每次动用失去什么；代价是否可逆；代价累积到什么程度会反噬）

**能力分布**

- （谁能用、谁不能用、谁能用多少；能力差距如何构成权力差距）

### 3.3 世界历史

**与主线相关的过去事件**

| 时间 | 事件 | 后果 |
|---|---|---|
| | | |

**故事开始时世界的状态**

- 政治 / 社会 / 自然或技术，各一句。

### 3.4 势力

| 势力 | 目标 | 手段 | 首领 |
|---|---|---|---|
| | | | |

**势力间的冲突点**：谁和谁在争什么，为什么不能各退一步。

### 3.5 关键地点

每个地点写：这是什么、谁在这里、为什么剧情需要它、哪些戏发生在这。

只写真正有戏的地点，不写地图百科。

### 3.6 道具与伏笔物件

| 物件 | 在哪里出现 | 在哪里开火 | 意义 |
|---|---|---|---|
| | | | |

**判据**：每个物件必须有「开火」位置。只出现不开火的物件是废笔。

### 3.7 知识层级表（最容易漏、最有用）

| 角色 | 知道 | 不知道 | 以为知道但其实错了 |
|---|---|---|---|
| | | | |

这张表决定信息差，而信息差是短剧最便宜的戏剧动力：主角知道的观众不知道（悬念）、观众知道的角色不知道（紧张）、两个角色互相不知道对方知道（反转）。

**写分镜之前的检查**：这一场的张力是不是来自某两个人在这张表上的错位？如果是，张力有根；如果不是，可能只是吵嘴。

## 四、设定的展示方式（禁对白倒设定）

**禁止**：角色用对白解释世界规则。

- 坏：「你也知道，我们这个世界的灵力分九品，突破第三品必须……」
- 坏：「自从三十年前那场大战之后，所有修士都不能……」

**允许的三种做法**：

1. **行动 + 常态反应**：先展示规则生效的现象，再让主角像对待日常一样反应。观众自动明白这在这里是常态。
2. **后果**：不解释规则，只展示违反规则的后果。
3. **物件**：让规则物化成一个可见的东西（一枚有裂纹的令牌、一个数字在跳的表盘）。

**判据**：把设定解释从台词里删掉，画面还能让人看懂，就说明展示做对了。

## 五、世界观与分场的接口

03 段的输出直接约束 04 段：

- 分场里的每一次能力使用，必须在「能做到」清单里；
- 每一次危机，必须被「做不到」清单或「代价」拦住过至少一次；
- 反派的压迫力来自能力分布，不是来自他喊得大声。

如果 04 段发现需要的能力不在清单里，**回 03 改规则**，不要在 04 里临时开挂。回改时记录到 `project-status.md` 的修订记录。

## 六、短剧形态的删减版

本项目主力形态是短剧，不需要整套设定百科。最小可用版本只要四件：

1. 系统的能与不能（各 3-5 条）
2. 使用的代价（1-2 条，且要在剧情里真正兑现）
3. 反派掌握什么主角没有的
4. 知识层级表（只列 3-5 个主要角色）

其余章节留给长片项目。

## 七、自检

- [ ] 「不能做」的限制真的在剧情里拦住过主角
- [ ] 代价在多个场景里累积，不是只提一次
- [ ] 能力分布构成权力差距
- [ ] 知识层级表能解释至少 3 场的张力来源
- [ ] 没有靠对白倒设定
- [ ] 每个伏笔物件都有开火位置
