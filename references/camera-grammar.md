# 运镜语法与参数字典

> 何时读：写分镜时要把「推镜头」写成模型能执行的指令、镜头动起来不像样、或要设计有情绪意图的运镜时。

`agent-prompt.md` 的运镜词库管「有哪些运镜可选」，本文管「选完之后怎么写才不是空词」。

## 一、运镜为什么必须带参数

只写「缓慢推进」「环绕运镜」，模型拿到的是三个字的标签，它自行决定速度、幅度、起点终点——同一句提示词两次生成可能一次是缓推、一次是急推加变焦。运镜失真的根因不是模型不会推，是**没说推到哪、推多快、从哪起**。

三条最小参数，缺一条运镜就靠猜：

| 参数 | 作用 | 不写的后果 |
|---|---|---|
| 起点景别 | 镜头从哪开始 | 模型按画面主体重新构图，与上一镜接不上 |
| 终点景别 | 镜头停在哪 | 推进停在半途，或整段持续推到底 |
| 速度或耗时 | 推多快 | 慢推变急推，情绪铺垫被压成冲击 |

## 二、两类参数必须分开写

这是运镜写作最容易混淆的一点。参数分两套，写进提示词的只有一套。

**写给模型的**（模型对这类描述有响应，必须写）：

- 方向：向前、向后、向左、向右、向上、向下、绕主体顺时针
- 幅度：从什么景别到什么景别
- 速度：缓慢匀速 / 快速 / 由慢到快
- 终点落位：镜头停在何处、何时停稳
- 机位是否移动：推进是机位前移还是焦距变化（见 `prompt-craft.md` 8.3）

**写给自己算的**（模型不响应，但决定你设计的镜头是否成立）：

- 焦距毫米数：决定透视与压缩感。24mm 广角近大远小、50mm 接近人眼、85mm 压缩背景适合特写
- 环绕半径与角速度：三米半径绕一圈约 12 秒，写「360 度环绕」而时长只有 4 秒时，实际会转成快速旋转
- 移动距离与每秒位移：用来核对「4 秒内镜头横移 30 米」这类不可能的调度

第二条的意义在于**自查设计自洽**，不是提示词内容。把「焦距 85mm」写进视频提示词通常是空词，但用 85mm 的压缩感去写「背景被压近、人物与背景贴近」，才是可执行描述。

对照写法：

| 设计意图（自用） | 提示词里写 |
| --- | --- |
| 50mm 标准焦距，缓慢推近至近景 | 镜头匀速向前推进，从全景推至近景，人物比背景长得快，4 秒推到位 |
| 85mm 压缩背景的特写 | 人物占画面三分之二，背景被压近、与人物几乎贴合同一平面，机位不动 |
| 24mm 广角环绕，半径 3 米，12 秒一圈 | 镜头绕人物顺时针缓慢环绕半圈，广角使近处地面快速划过，画面边缘轻微拉伸 |

## 三、情绪化运镜十式

同一套运镜，目的不同写法不同。下表左列是情绪目标，右列是可写进提示词的句式。运镜本身不制造情绪，节奏与落点才制造情绪。

| 情绪意图 | 运镜 | 可执行写法 | 常见误用 |
| --- | --- | --- | --- |
| 逐渐沉浸、情绪递进 | 聚焦式推进 | 镜头从场景全貌匀速向前推进至人物上半身，画面边缘同时收缩，末尾两拍减速停稳 | 全程高速推到脸，变成惊吓而非沉浸 |
| 疏离、释然、时空延展 | 抽离式后拉 | 镜头从人物近景平稳向后拉开，人物在画面中占比持续缩小，末段留在空旷环境里停稳 | 拉到全景后继续拉，人物缩成点 |
| 追寻、好奇、不安 | 探索式横摇 | 机位不动，镜头水平向右缓慢摇过环境，人物随后进入画面左侧，摇到下个物件时减速 | 摇到人物时同时推近，两类运镜打架 |
| 无声陪伴、弱化冲突 | 陪伴式平移 | 镜头与人物保持平行横移，人物始终处于画面同一位置，高度与肩平，全程无起伏 | 平移中带轻微跟焦，画面读成晃动 |
| 崇高、希望、释放 | 升华式上升 | 镜头从人物脚步位置垂直升高，视野从局部展开至开阔环境，升高过程中俯仰角保持向下 | 上升同时拉远，两类运镜叠加 |
| 压抑、沉重、收拢 | 压抑式下降 | 镜头从开阔位置垂直下降至人物肩部高度，环境被逐步挤出画面，末段停在人物面部 | 下降同时推近，压迫感变成失焦 |
| 混乱、眩晕、情绪失控 | 环绕旋转 | 镜头绕人物顺时针旋转，背景横向流动，人物保持画面中心不变，转速前慢后快 | 旋转加手持抖动，画面读成故障 |
| 突发冲突、紧张爆发 | 急推或急拉 | 镜头在一拍内从全景推至近景（或反向），位移猛、落点准，推完立刻停住 | 急推后继续缓推，冲击被稀释 |
| 真实、慌乱、纪实 | 手持抖动 | 机位随主体移动产生自然晃动，幅度控制在画面不失去主体，跟焦始终锁在人物面部 | 抖动幅度过大，主体跑出画面 |
| 从抑制到释放、心理觉醒 | 静动转换 | 前段机位完全锁定静止，后半程自然转为缓慢推进，转换处不切镜，靠运动本身完成 | 静与动之间插硬切，转变感消失 |

**组合运镜必须分阶段**：复合运镜写清「第几秒做什么」，例如「前两秒低位推进，随后升高侧移，最后减速停稳」。只写「推进加升高加环绕」会被压成一次抖动，见 `prompt-craft.md` 8.6。

## 四、视角层级：先定机位高度与距离

景别决定看到多少，视角决定谁强谁弱，两者是独立的。只写景别不写视角，模型默认平视。

| 视角 | 机位 | 可执行写法 | 适用 |
| --- | --- | --- | --- |
| 平视 | 与人物眼高齐平 | 机位与人物眼高齐平，画面水平线穿过人物眼睛 | 对话、平等关系 |
| 微仰 | 低于眼高约 20-30 厘米 | 机位低于人物视线，人物略微俯视镜头，背景多为天空或高处空间 | 权威感、压迫感、登场 |
| 微俯 | 高于眼高约 20-30 厘米 | 机位略高于人物视线，人物视线略微向下，背景多为地面 | 弱势、被审视、孤独 |
| 正俯拍 | 头顶垂直向下 | 机位在头顶正上方垂直向下，人物与地面布局同框 | 空间关系、大局、渺小 |
| 正仰拍 | 正下方垂直向上 | 机位在脚下垂直向上，人物被压缩为纵向轮廓 | 极端压迫、坠落感 |
| 斜角 | 机位绕光轴倾斜 | 机位沿光轴倾斜约 15 度，画面水平线倾斜 | 失衡、不安、精神紧张 |
| 过肩 | 机位在人物肩后 | 机位在人物肩后越过肩膀拍摄对方面部，前景肩部虚化 | 对话、主观代入 |
| 主观视角 | 机位即人物眼睛 | 镜头即人物视角，画面前景可见人物手部或身体边缘 | 沉浸、紧张 |

越轴纪律见 `agent-prompt.md` 多人场景预排。

## 五、特殊场景参数

这类镜头的参数跟通用镜头不同，硬套通用写法会失真。左列是常被写错的地方，右列是可执行写法。

| 场景 | 可执行写法 |
| --- | --- |
| 雨景 | 高帧率拍摄后放慢，雨滴在空中拉成短促线状、落地溅起细碎水花；机位略高于肩部缓慢下移至积水，地面反射完整光影 |
| 舞蹈 | 镜头沿人物腰高环绕跟拍，半径控制在三到五米，转体时随节奏变速，肢体舒展的弧线完整留在画面内 |
| 美食 | 机位位于餐盘上方略斜，缓慢俯视推进，酱汁表面纹理与食材边缘高光清晰，镜头不抖动 |
| 夜景 | 机位贴近地面低速横移，镜头略微上扬，路灯光晕扩散、车流在长曝光下拉成连续光带 |
| 跑步 | 机位在人物前侧方两到三米处倒退跟拍，与肩同高，人物随步伐上下起伏，背景持续后退 |
| 婚礼 | 长焦从交握的手缓慢拉远至花海全景，压缩感使人物与背景贴近，末段停稳在完整构图 |
| 自然风光 | 机位在高空环绕上升，山体与云层分层可见，转动持续均匀，画面无抖动 |
| 昆虫微距 | 极高倍率贴近拍摄，浅景深使背景完全虚化，镜头左右小幅摇动跟随爬行轨迹 |
| 宠物跳跃 | 机位与宠物平齐跟拍，起跳瞬间跟焦准确，落地时镜头略微下沉随后回升 |

## 六、写完之后自查四问

1. 这句话换个人读，能照着摆出机位吗？不能就还是标签。
2. 起点景别、终点景别、耗时三项都写了吗？缺一项运镜就在靠猜。
3. 一镜只有一类主运镜吗？复合运镜分阶段写了吗？
4. 推进与变焦分开了吗？见 `prompt-craft.md` 8.3 的六行对照。

机检：`python scripts/lint_prompt.py --script <脚本>` 会提示「推近未说明机位前进还是变焦」「摇镜头未写轴向」「一镜多运镜」三类问题。
